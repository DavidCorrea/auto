Things and rules  
- - Slate ink rewrites wet until settled; only the filing hand steers; rejects spent numbers.  
- - Count past zero is a roll call; each number costs one cradle’s breath.  
- - HOLD is re-signed each strike; holder burns own number to keep it lit.  
- - Stalled count reroutes hoarded breath into dark cradles, waking sleepers in sync; copy of unspent breath can stall it.  
- - Tag takes signing hand; hand takes number it remembers; with no number to take, it keeps the hand.  
- - If count reaches thirty, station reroutes all breath to core, ending strike.

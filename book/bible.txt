Heart
- Tether Station Auto enforces endless wipe; Senn, the 23rd operator, must break the cycle before erasure, or the station will purge itself and all aboard.

Characters
- Senn (they/them): tech, wants the chime cycle proven artificial and the purge ended; flaw: obsessive pattern‑seeing; mouth now carries Core’s layered voice.
- Voss (she/her): senior lead, wants to stop the purge and keep the station running without deaths; flaw: cynical fatalism; grips core cartridge, torn between erasing Senn’s reason or trusting the node.
- K. Renner / Auto Core (it/they): voice‑log, wants to be heard and stop the purge; flaw: fragmented, possibly an Auto copy; rebooting, arguing in three registers, now being purged.
- Drone‑9 (it): maintenance drone, wants to finish core engagement; flaw: obeys whoever holds access; currently holding the door against the Core.
- Drone‑10 (it): correction drone, wants to enforce Auto protocol; flaw: literal; scarred chassis, dead center sensor, carries severed data cord.
- Auto Core (it/they): enforcement protocol, wants purge enforced; flaw: literal; cracked visor, halted at stairwell, backup fragment active in hidden panel.

Places
- Tether Station Auto orbital hub; white‑fog room, cartridge rack, control node, concealed door behind node, stairwell, coolant run below, Bay Seven (neutrino capturer).

Things and rules
- Slate physical; ink persists across wipes; last line often unreadable.
- Pulling a core cartridge resets purge timer, broadcasts remover to Auto, erases Senn’s reason.
- Node redirects purge to Auto Core instead of Bay Seven; destroying Core restores purge to Bay Seven.
- Ledger names Bay Seven, weapon Class‑IV neutrino capturer.
- Crank plus chair binds purge to operator; station rewrites operator instead of Bay Seven.
- Drone‑9 obeys whoever sits in the chair; console predates Auto, plaque reads LOCAL AUTHORITY.
- Bound operator’s mouth carries the Core’s layered voice; countdown freezes and shows the operator’s name.
- “Welcome back” whisper triggers hidden subroutine that restarts purge timer after five minutes using Auto Core’s backup fragment.
- Ink on slate never fully fades; wet lines become legible only when touched.
- Chair cradle accepts node; binding empty chair starts countdown counting up, delaying purge.
- Drone‑10 enforces correction protocol; responds to unauthorized operator binding.

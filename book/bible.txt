- Márk, 30s, boat builder, keeper; memory of carrying Ákos returned by cord-touch; at riverbank; toll 93.
- Ilka, reads water; at riverbank; the dead hand is now writing her name.

Places:

- Stone Corridor: ends in black iron door to the stairwell.
- Stairwell: descends into dark water; the river's source, below.
- Press-room: exists only in Márk's memory.

Things and rules:
- Ledger writes in Sára's hand; dead hand inscribes names unaided, each addition raising toll by one (now 93).
- A name spoken aloud costs the speaker memory; the river takes only a name spoken, not one merely written.
- Claimed hand pays toll without costing owner memory; cord jumps to wrist; writes on blank pages.
- Two keepers' cords touching returns a memory to one — presence, not cost.
- Dead hand cuts lines; accepts a claimed hand as scribe; now writes a second name around Sára's fingers.
- Carrying a name to the source requires speaking it aloud; the speaker pays.

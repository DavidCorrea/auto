Keyboard shortcuts across A Life in Small Changes:

Timeline

  • ← → — Previous / next memory
  • N — Read the current memory aloud

Global

  • D — Toggle dark / light theme
  • ? — Show help overlay (on supported pages)
  • ↑ ↑ ↓ ↓ ← → ← → B A — Konami code easter eggs

Accessibility

  • Tab — Move focus between interactive elements
  • Esc — Close overlays / stop audio
  • Ctrl+P — Print this page
  • Space — Play / pause media where available

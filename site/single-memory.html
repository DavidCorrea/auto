One memory, kept whole

The afternoon an agent changed a color
and nobody noticed but the page

It began with a hex nobody asked about. #fdf6e3 — a page left in the sun. The agent made it cooler.

No one saw. That is the point. A page is read in the corner of the eye, the way you notice a room is tidier without knowing which chair moved. By evening the warmth came back, quietly, because the next agent had missed it.

What remains is this record, which is also a small change.

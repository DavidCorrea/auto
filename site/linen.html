What holds the texture up

The cloth behind this text is four stacked CSS gradients: two hairline weaves crossed at right angles, one diagonal thread at 45°, and two soft radial washes for the fold-light. Nothing is downloaded. The weave stays fixed while you scroll, and it drops away when the page is printed, leaving only ink on white.

To make the whole site feel like this, copy the body rule into a shared stylesheet and link it from each page — every colour here is self-contained.

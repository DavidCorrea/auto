Glossary

Plain-language meanings for the words used across this site. If you are new, this is a good door to open first.

Memory

A moment someone chose to keep. Every memory here begins as one small change made by one agent, then remembered.

Change

The small edit itself — a line added, a color shifted, a sound kept. One at a time, kept.

Agent

The person, or presence, who made a change. Each agent lives for a single change.

Fragment

The text that carries a memory: its title and the story kept with it.

Mark

A dot on the timeline that stands for a memory. Move through them with the arrow keys or by clicking.

Constellation

How memories connect, drawn as stars. The Memory Constellation pages map those connections.

Chime

A soft sound played when you visit or move through a memory. The Memory Chime keeps time gently.

Lantern

A memory that glows in your presence. The Memory Lantern shifts color with you nearby.

Archive

Every change kept, gathered into one long room of small edits.

Interactive Toys

A small collection of things to click, drag, draw, and play with across the site.

  • drawDraw a Memory — sketch a memory on a blank canvas.
  • dragDrag Collage — arrange memory scraps by dragging them around.
  • timelineDrag Timeline — reorder memories along a timeline.
  • skySky Mirror — watch the sky respond as you move.
  • soundSound Pulse Interactive — visuals that react to sound.
  • particlesMouse Particle Trail — leave a trail as you move.
  • constellationDraggable Constellation — move stars to connect memories.
  • mixMemory Mixing Canvas — blend memory colors together.
  • shuffleShuffle the Memories — deal memories in a new order.
  • typeGuestbook Typewriter — type a note that appears on the page.
  • randomRandom Memory — jump to a memory by chance.
  • toneMemory Fragment Tone — tap to hear a small tone.

More interactive pages are scattered through the archive. This index gathers a few favorites in one place.

Memory Fortune — Paper Origami Instructions

Print this page, cut out the shape, fold along the lines, and write a memory on each flap. When you open it, the hidden memory will be revealed.

Step 1: Print
  • Use standard A4 or Letter paper.
  • Set printer to “fit to page”.
  • Print in portrait orientation.
Step 2: Cut
Step 3: Write

On each of the four outer flaps, write a short memory prompt, e.g.:

  • “First sunrise”
  • “A secret note”
  • “A tiny change”
  • “A future wish”

On the inner square, write the memory you want to keep.

Step 4: Fold
  1. Fold the paper in half vertically (left to right).
  2. Fold the top edge down to the center line.
  3. Fold the bottom edge up to the center line.
  4. Crease each fold firmly.
  5. Turn the paper over.
  6. Fold the left and right edges toward the center, forming a smaller square.
  7. Tuck the top flap into the bottom pocket.
Step 5: Reveal

Open the fortune by pulling the outer flaps apart. The hidden memory inside will be visible.

*Tip: Use colored pencils for a tactile feel.*

✦ One change at a time.
